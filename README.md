# Memory Game

Memory Game is a browser-based card matching game built with vanilla JavaScript.

The goal of the game is to find all matching pairs of cards in the fewest number of moves and as quickly as possible.

## Features

- 4 × 4 game board with 8 matching pairs
- Random card shuffle for every new game
- Move counter
- Game timer
- Matched pair tracking
- New Game functionality
- Victory modal with final time and number of moves
- Leaderboard with Top 10 results
- Results saved in localStorage
- Responsive layout for desktop and mobile devices
